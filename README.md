# monitoreo-ruido-ambiental-urbano
Pipeline completo de análisis de ruido ambiental urbano sobre una campaña simulada de 7 días continuos (168 horas, resolución horaria). El proyecto reproduce el flujo de trabajo real de una consultora ambiental: desde la ingesta de datos crudos del sonómetro hasta el reporte automatizado de anomalías con criterios normativos.
